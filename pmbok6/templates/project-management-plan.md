## 3. Вспомогательные планы (кратко: цель, ключевые правила, ответственный)
| Компонент | Ключевые решения |
|---|---|
| Содержание | Как готовится ИСР, как принимаются результаты (5.5), как обрабатываются изменения содержания |
| Требования | Приоритизация, трассировка (RTM), управление конфигурацией требований |
| Расписание | Инструмент, единицы, точность, пороги контроля (напр. SPI < 0,9 → эскалация), правила обновления |
| Стоимость | Единицы, точность, пороги (CPI < 0,9), методы EV (0/100, 50/50…), контрольные счета |
| Качество | Стандарты, метрики, роли, аудиты, тестирование |
| Ресурсы | Роли (RACI), приобретение, обучение, признание, контроль физ. ресурсов |
| Коммуникации | См. `communications-plan.md` |
| Риски | Методология, шкалы P/I, аппетит, пороги, бюджет, частота пересмотра |
| Закупки | Что закупаем, типы контрактов, критерии выбора, график |
| Вовлечение стейкхолдеров | Текущий/желаемый уровни, стратегии |
| **Управление изменениями** | Кто может подавать, CCB (состав), уровни полномочий (РП до [ ] ₽/дн, CCB выше), SLA рассмотрения |
| **Управление конфигурацией** | Элементы конфигурации, версии, хранилище, аудит |
