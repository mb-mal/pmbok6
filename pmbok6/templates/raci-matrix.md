# Шаблон: Матрица ответственности (RACI)

> Процесс 9.1. **R** — исполняет · **A** — утверждает и отвечает за результат (**ровно один** на строку) · **C** — консультирует (двусторонняя связь) · **I** — информируется (односторонняя).

| Работа / результат (код ИСР) | Спонсор | РП | Аналитик | Разработчик | QA | Заказчик |
|---|---|---|---|---|---|---|
| Устав проекта | A | R | C | | | C |
| Требования (1.1) | I | A | R | C | C | C |
| Разработка (1.2) | | A | C | R | C | |
| Тестирование (1.3) | | A | C | C | R | I |
| Приёмка (5.5) | I | R | | | C | A |

**Проверки:** в каждой строке ровно один A и хотя бы один R · нет столбцов без R/A (лишняя роль?) · у одного человека не слишком много R (перегрузка) · A и R могут совпадать.
