# Формулы PMBOK 6

> Для точных вычислений используй `scripts/pmcalc.js` (Node.js, без зависимостей). Разобранные примеры — `worked-examples.md`.

## 1. Освоенный объём (EVM)

### Базовые величины
| Показатель | Название | Смысл |
|---|---|---|
| **PV** | Planned Value | Плановая стоимость работ, запланированных к дате |
| **EV** | Earned Value | Плановая стоимость фактически **выполненных** работ = % выполнения × BAC |
| **AC** | Actual Cost | Фактические затраты на выполненные работы |
| **BAC** | Budget at Completion | Базовый план по стоимости (сумма PV всего проекта) |

### Отклонения и индексы
| Показатель | Формула | Хорошо | Плохо |
|---|---|---|---|
| **SV** | EV − PV | > 0 опережение | < 0 отставание |
| **CV** | EV − AC | > 0 экономия | < 0 перерасход |
| **SPI** | EV / PV | > 1 | < 1 |
| **CPI** | EV / AC | > 1 | < 1 |
| **VAC** | BAC − EAC | > 0 уложимся | < 0 превысим |

Мнемоника: **EV всегда первым**; отклонение — минус, индекс — деление. Отрицательное = плохо, < 1 = плохо.
⚠️ SV/SPI на завершении проекта всегда = 0 / 1 (EV = PV = BAC) — поэтому в конце проекта SPI теряет смысл; используй КП или earned schedule.

### Прогноз по завершении (EAC)
| Формула | Когда применять |
|---|---|
| **EAC = BAC / CPI** | Отклонения **типичные** — текущая эффективность сохранится |
| **EAC = AC + (BAC − EV)** | Отклонения **нетипичные/разовые** — остальное по плану |
| **EAC = AC + (BAC − EV) / (CPI × SPI)** | На остаток влияют и стоимость, и сроки (жёсткая дата финиша) |
| **EAC = AC + ETC (снизу вверх)** | Исходные оценки **неверны** — нужна новая оценка |

### Оценка до завершения (ETC)
| Формула | Когда |
|---|---|
| ETC = EAC − AC | Общий случай |
| ETC = (BAC − EV) / CPI | Типичные отклонения |
| ETC = BAC − EV | Нетипичные отклонения |
| ETC = новая оценка | Переоценка оставшейся работы |

### Индекс производительности до завершения (TCPI)
| Формула | Цель |
|---|---|
| **TCPI = (BAC − EV) / (BAC − AC)** | Уложиться в BAC |
| **TCPI = (BAC − EV) / (EAC − AC)** | Уложиться в утверждённый EAC |

TCPI > 1 — нужно работать эффективнее, чем по плану; TCPI заметно больше CPI → цель BAC, скорее всего, недостижима.

### Прочее
- **% выполнения** = EV / BAC · **% израсходовано** = AC / BAC
- **Правила начисления EV** для пакетов: 0/100, 20/80, 50/50, взвешенные вехи, % выполнения (оценка), уровень усилий (LOE), распределённые усилия.

## 2. Расписание

### Трёхточечная оценка (O — оптимистичная, M — наиболее вероятная, P — пессимистичная)
| Формула | Смысл |
|---|---|
| **tE = (O + 4M + P) / 6** | Бета-распределение (PERT) |
| **tE = (O + M + P) / 3** | Треугольное распределение |
| **σ = (P − O) / 6** | Стандартное отклонение (PERT) |
| **σ² = ((P − O) / 6)²** | Дисперсия |
| **σ_пути = √Σσ²ᵢ** | Для пути складываются **дисперсии**, не σ |

Доверительные интервалы (норм. распределение): ±1σ ≈ 68,27% · ±2σ ≈ 95,45% · ±3σ ≈ 99,73% · ±6σ ≈ 99,99966%.

### Метод критического пути (CPM)
| Параметр | Формула |
|---|---|
| **Общий резерв** (total float) | LS − ES = LF − EF |
| **Свободный резерв** (free float) | ES(самого раннего преемника) − EF(операции) |
| **Резерв проекта** (project float) | Директивный срок − ранний финиш проекта |
| **Критический путь** | Самый длинный путь; общий резерв = 0 (или минимальный/отрицательный) |

Две конвенции проходов — **выбери одну и придерживайся её**:
| | Конвенция «с нуля» (ПО, большинство задач PMP) | Конвенция «с единицы» (день начала = 1) |
|---|---|---|
| Прямой проход | EF = ES + Д; ES след. = max(EF пред.) | EF = ES + Д − 1; ES след. = max(EF пред.) + 1 |
| Обратный проход | LS = LF − Д; LF пред. = min(LS след.) | LS = LF − Д + 1; LF пред. = min(LS след.) − 1 |

Резервы и КП в обеих конвенциях одинаковы.

### Сжатие расписания
- **Стоимость сжатия за период** = (Стоимость при сжатии − Нормальная стоимость) / (Нормальная длительность − Длительность при сжатии)
- Сжимай **операции КП** с **наименьшей** стоимостью за период; после каждого шага проверяй, не появился ли новый КП.

### Agile-метрики
- **Скорость (velocity)** = story points, завершённые за итерацию (средняя за 3–5 итераций)
- **Число итераций** = ⌈Остаток бэклога / velocity⌉
- **Время цикла** (Little's law) = WIP / Пропускная способность

## 3. Риски

| Формула | Смысл |
|---|---|
| **EMV = P × I** | Ожидаемая денежная стоимость риска (угроза: I < 0, возможность: I > 0) |
| **Σ EMV** | Основа резерва на непредвиденные (известные риски) |
| **Оценка риска = P × I** | Для матрицы вероятности и воздействия (баллы/доли) |
| **EMV узла решения** = затраты варианта + Σ(Pᵢ × Исходᵢ) | Дерево решений: выбирается лучший EMV (макс. выигрыш / мин. затраты) |

## 4. Коммуникации
**Каналы = n(n − 1) / 2**, где n — число людей (включая РП).
Прирост каналов при добавлении k человек = C(n+k) − C(n). Пример: 10 → 45 каналов; 13 → 78 (+33).

## 5. Закупки и контракты

| Контракт | Прибыль продавца | Цена для покупателя |
|---|---|---|
| **FFP** | Цена − Факт. затраты | Фиксированная цена |
| **FPIF** | Целевая прибыль + (Целевые затраты − Факт) × Доля продавца | Факт + прибыль, **но не выше потолка цены** |
| **CPFF** | Фиксированное вознаграждение | Факт + фикс. вознаграждение |
| **CPIF** | Целевое вознаграждение + (Целевые затраты − Факт) × Доля продавца (с min/max) | Факт + вознаграждение |
| **CPAF** | Базовое + премия по субъективной оценке покупателя | Факт + вознаграждение |
| **T&M** | Заложена в ставку | Ставка × часы + материалы |

**PTA (точка полного принятия, FPIF):** PTA = (Потолок цены − Целевая цена) / Доля покупателя + Целевые затраты.
Выше PTA каждый рубль перерасхода полностью несёт продавец.

## 6. Финансовый выбор проекта (бизнес-кейс)

| Метод | Формула / правило |
|---|---|
| **PV (приведённая стоимость)** | PV = FV / (1 + r)ⁿ |
| **NPV** | Σ CFₜ/(1+r)ᵗ − Инвестиции; выбирай **больший** NPV (срок уже учтён) |
| **IRR** | Ставка, при которой NPV = 0; больше — лучше |
| **Срок окупаемости** | Инвестиции / Годовой приток; меньше — лучше |
| **BCR** | Выгоды / Затраты; > 1 выгодно |
| **ROI** | (Выгоды − Затраты) / Затраты |
| **Упущенная выгода** (opportunity cost) | Ценность **не выбранного** лучшего варианта |

⚠️ **Невозвратные затраты** (sunk cost) не учитываются в решениях о продолжении проекта. Амортизация: линейная = (Стоимость − Остаточная) / Срок.

## 7. Качество
- **Контрольные карты**: верхняя/нижняя контрольные границы = среднее ± 3σ
- **Правило семи**: 7 точек подряд по одну сторону среднего → неслучайная причина
- **Парето 80/20**: ~80% проблем от ~20% причин

## Шпаргалка
```
SV = EV − PV    CV = EV − AC     SPI = EV/PV    CPI = EV/AC
EAC = BAC/CPI                    (типичные отклонения)
EAC = AC + (BAC − EV)            (нетипичные)
EAC = AC + (BAC − EV)/(CPI×SPI)  (стоимость и сроки)
EAC = AC + ETC                   (переоценка)
ETC = EAC − AC   VAC = BAC − EAC
TCPI = (BAC − EV)/(BAC − AC)     или /(EAC − AC)
tE = (O + 4M + P)/6   σ = (P − O)/6   σ_пути = √Σσ²
TF = LS − ES = LF − EF    FF = ES(преемника) − EF
Каналы = n(n − 1)/2       EMV = P × I
PTA = (Потолок − Целевая цена)/Доля покупателя + Целевые затраты
```
