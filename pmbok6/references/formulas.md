# Формулы PMBOK 6

## Управление стоимостью — Earned Value Management (EVM)

### Базовые показатели

| Показатель | Полное название | Формула | Описание |
|-----------|----------------|---------|----------|
| **PV** | Planned Value | — | Плановая стоимость запланированных работ |
| **EV** | Earned Value | — | Плановая стоимость фактически выполненных работ |
| **AC** | Actual Cost | — | Фактическая стоимость выполненных работ |
| **BAC** | Budget at Completion | — | Бюджет по завершении (сумма всех PV) |

### Отклонения

| Показатель | Формула | > 0 означает | < 0 означает |
|-----------|---------|-------------|-------------|
| **SV** (Schedule Variance) | EV − PV | Опережение графика | Отставание от графика |
| **CV** (Cost Variance) | EV − AC | Экономия бюджета | Перерасход бюджета |
| **VAC** (Variance at Completion) | BAC − EAC | Проект уложится в бюджет | Проект превысит бюджет |

### Индексы

| Показатель | Формула | > 1 означает | < 1 означает |
|-----------|---------|-------------|-------------|
| **SPI** (Schedule Performance Index) | EV / PV | Опережение | Отставание |
| **CPI** (Cost Performance Index) | EV / AC | Экономия | Перерасход |

### Прогнозы (EAC — Estimate at Completion)

| Метод | Формула | Когда применять |
|-------|---------|-----------------|
| **EAC₁** (типичный CPI) | BAC / CPI | Текущий CPI сохранится до конца проекта |
| **EAC₂** (оставшиеся по плану) | AC + (BAC − EV) | Отклонение — разовое, дальше по плану |
| **EAC₃** (учёт CPI и SPI) | AC + [(BAC − EV) / (CPI × SPI)] | Нужно соблюсти и сроки, и бюджет |
| **EAC₄** (новая оценка) | AC + новая ETC | Исходный план недействителен |

### До завершения

| Показатель | Формула | Описание |
|-----------|---------|----------|
| **ETC** (Estimate to Complete) | EAC − AC | Сколько ещё потребуется для завершения |
| **TCPI** (To-Complete Performance Index) | (BAC − EV) / (BAC − AC) | Какая эффективность нужна, чтобы уложиться в BAC |
| **TCPI** (на основе EAC) | (BAC − EV) / (EAC − AC) | Какая эффективность нужна, чтобы уложиться в EAC |

### Формулы ETC

| Метод | Формула |
|-------|---------|
| Оставшиеся работы по плану | ETC = BAC − EV |
| Переоценка оставшихся работ | ETC = новая оценка оставшихся работ |

### Правило 50/50, 20/80, 0/100

Способы начисления EV для незавершённых пакетов работ:
- **50/50**: 50% EV при старте, 50% при завершении
- **20/80**: 20% EV при старте, 80% при завершении
- **0/100**: 0% до завершения, 100% при завершении

## Управление расписанием — Критический путь и PERT

### PERT (оценка по трём точкам)

| Формула | Применение |
|---------|-----------|
| **tE = (O + 4M + P) / 6** | Ожидаемая длительность (бета-распределение) |
| **tE = (O + M + P) / 3** | Треугольное распределение (равные веса) |
| **σ = (P − O) / 6** | Стандартное отклонение |
| **σ² = ((P − O) / 6)²** | Дисперсия |

Где: **O** = оптимистичная, **M** = наиболее вероятная, **P** = пессимистичная оценка.

### Критический путь

| Параметр | Формула |
|----------|---------|
| **Резерв (Float/Slack)** | LS − ES = LF − EF |
| Критический путь | Путь с нулевым (или наименьшим) резервом |

**ES** — ранний старт, **EF** — ранний финиш, **LS** — поздний старт, **LF** — поздний финиш.

**Прямой проход**: ES + Длительность − 1 = EF. ES следующей = EF предыдущей + 1.
**Обратный проход**: LF − Длительность + 1 = LS.

## Управление рисками

| Формула | Описание |
|---------|----------|
| **EMV = P × I** | Ожидаемая денежная стоимость (Probability × Impact) |
| **Сумма EMV** | Резерв на непредвиденные обстоятельства (contingency reserve) |
| **PI Score = P × I** | Оценка риска по матрице вероятности/воздействия |

---

## Управление коммуникациями

| Формула | Применение |
|---------|-----------|
| **n × (n − 1) / 2** | Количество каналов коммуникаций, где n = число стейкхолдеров |

Пример: 10 стейкхолдеров → 10 × 9 / 2 = 45 каналов.

## Управление закупками

### Point of Total Assumption (PTA) — для контрактов FPIF

**PTA = [(Ceiling Price − Target Price) / Buyer's Share Ratio] + Target Cost**

Применяется только для контрактов с фиксированной ценой и поощрением (FPIF). За пределами PTA все перерасходы ложатся на подрядчика.

### Расчёт поощрения

| Тип контракта | Прибыль подрядчика |
|---------------|-------------------|
| **CPFF** | Fixed Fee (фиксированная) |
| **CPIF** | Target Fee + (Target Cost − Actual Cost) × Seller's Share |
| **FPIF** | (Target Price − Target Cost) + (Target Cost − Actual Cost) × Seller's Share |

## Анализ «что если» (What-If Analysis)

Моделирование сценариев: если длительность операции X изменится на Y дней, как это повлияет на критический путь и дату завершения проекта?

**Метод Монте-Карло**: многократный прогон модели расписания/стоимости со случайными значениями длительностей/стоимостей для оценки вероятности завершения к заданной дате / в рамках бюджета.

---

## Дерево решений (Decision Tree)

**EMV решения = Σ (Вероятность исхода × Денежная стоимость исхода)**

Выбирается вариант с наибольшей EMV.

## Быстрый справочник (шпаргалка)

```
SV = EV − PV          (>0 = опережение)
CV = EV − AC          (>0 = экономия)
SPI = EV / PV         (>1 = хорошо)
CPI = EV / AC         (>1 = хорошо)

EAC = BAC / CPI       (типичный сценарий)
EAC = AC + (BAC − EV) (разовое отклонение)
ETC = EAC − AC
TCPI = (BAC−EV) / (BAC−AC)

PERT = (O + 4M + P) / 6
σ = (P − O) / 6

Каналы = n(n−1)/2
EMV = P × I
PTA = [(Ceiling − Target Price) / Buyer Share] + Target Cost
```
