# Управление рисками — ITTO

## 11.1 Планирование управления рисками (PL)
Входы: Устав, план УП, документы, ФСП, АПО
Инструменты: Экспертная оценка, анализ данных (анализ стейкхолдеров), совещания
Выходы: План управления рисками

## 11.2 Идентификация рисков (PL)
Входы: План УП, документы, соглашения, закупочная документация, ФСП, АПО
Инструменты: Экспертная оценка, сбор данных (мозговой штурм, метод Дельфи, интервью, анализ первопричин), анализ данных (SWOT, анализ допущений, анализ документов), межличностные навыки (фасилитация), контрольные списки, подсказки
Выходы: Реестр рисков, отчёт по рискам, обновления документов

## 11.3 Качественный анализ рисков (PL)
Входы: План УП, документы, ФСП, АПО
Инструменты: Экспертная оценка, сбор данных (интервью), анализ данных (оценка качества данных, оценка вероятности и воздействия), межличностные навыки (фасилитация), категоризация рисков, отображение данных (матрица вероятности и воздействия, иерархические диаграммы), совещания
Выходы: Обновления документов (реестр рисков с PI score и приоритетами)

## 11.4 Количественный анализ рисков (PL)
Входы: План УП, документы, ФСП, АПО
Инструменты: Экспертная оценка, сбор данных (интервью), анализ неопределённости, анализ чувствительности (диаграмма «торнадо»), анализ дерева решений, имитационное моделирование (Монте-Карло), анализ влияния на проект
Выходы: Обновления документов (вероятностный анализ проекта, приоритетный список рисков, тренды)

## 11.5 Планирование реагирования на риски (PL)
Входы: План УП, документы, ФСП, АПО
Инструменты: Экспертная оценка, сбор данных (интервью), межличностные навыки (фасилитация), стратегии для угроз (уклонение, передача, снижение, принятие), стратегии для возможностей (использование, увеличение, разделение, принятие), стратегии для совокупного риска, анализ данных (альтернатив, «затраты-выгоды»), принятие решений
Выходы: Запросы изменений, обновления документов (планы реагирования, резервы на непредвиденные обстоятельства, остаточные и вторичные риски)

## 11.6 Осуществление реагирования на риски (EX)
Входы: План УП, документы, АПО
Инструменты: Экспертная оценка, межличностные навыки (влияние), ИСУП
Выходы: Запросы изменений, обновления документов

## 11.7 Мониторинг рисков (MC)
Входы: План УП, документы, данные исполнения, отчёты об исполнении, АПО
Инструменты: Анализ данных (анализ исполнения, анализ резервов), аудиты рисков, совещания
Выходы: Информация об исполнении, запросы изменений, обновления документов
