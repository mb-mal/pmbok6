# Управление ресурсами — ITTO

## 9.1 Планирование управления ресурсами (PL)
Входы: Устав, план УП, документы, ФСП, АПО
Инструменты: Экспертная оценка, отображение данных (иерархические диаграммы, матрица ответственности RACI, текстовые описания ролей), организационная теория, совещания
Выходы: План управления ресурсами, устав команды, обновления документов

## 9.2 Оценка ресурсов операций (PL)
Входы: План УП, документы, ФСП, АПО
Инструменты: Экспертная оценка, оценка «снизу-вверх», оценка по аналогам, параметрическая, анализ данных, ИСУП, совещания
Выходы: Требования к ресурсам, основа оценок, иерархическая структура ресурсов, обновления

## 9.3 Приобретение ресурсов (EX)
Входы: План УП, документы, ФСП, АПО
Инструменты: Принятие решений (многокритериальный анализ), межличностные навыки (переговоры), предварительное назначение, виртуальные команды
Выходы: Назначения персонала, календари ресурсов, запросы изменений, обновления

## 9.4 Развитие команды проекта (EX)
Входы: План УП, документы, ФСП, АПО
Инструменты: Колокация (war room), виртуальные команды, коммуникационные технологии, межличностные навыки (управление конфликтами, влияние, мотивация, переговоры, построение команды), признание и вознаграждение, обучение, индивидуальная и командная оценка, совещания
Выходы: Оценка исполнения команды, запросы изменений, обновления

## 9.5 Управление командой (EX)
Входы: План УП, документы, отчёты об исполнении, оценка исполнения команды, ФСП, АПО
Инструменты: Межличностные навыки (управление конфликтами, принятие решений, эмоциональный интеллект, влияние, лидерство), ИСУП
Выходы: Запросы изменений, обновления плана и документов

## 9.6 Контроль ресурсов (MC)
Входы: План УП, документы, данные исполнения, соглашения, АПО
Инструменты: Анализ данных (анализ альтернатив, «что если», трендов, отклонений, исполнения), решение проблем, межличностные навыки, ИСУП
Выходы: Информация об исполнении, запросы изменений, обновления
