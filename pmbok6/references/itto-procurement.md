# Управление закупками — ITTO

## 12.1 Планирование управления закупками (PL)
Входы: Устав, план УП, документы, ФСП, АПО
Инструменты: Экспертная оценка, сбор данных (исследование рынка), анализ данных (анализ «производить или покупать»), выбор источника, совещания
Выходы: План управления закупками, стратегия закупок, документация по закупкам, техзадание на закупку (SOW), критерии выбора поставщика, решение «производить или покупать», запросы изменений

## 12.2 Проведение закупок (EX)
Входы: План УП, документы, закупочная документация, предложения продавцов, ФСП, АПО
Инструменты: Экспертная оценка, реклама, конференции участников торгов, анализ данных (оценка предложений), межличностные навыки (переговоры)
Выходы: Выбранные продавцы, соглашения (контракты), запросы изменений, обновления

## 12.3 Контроль закупок (MC)
Входы: План УП, документы, соглашения, закупочная документация, одобренные запросы изменений, данные исполнения, ФСП, АПО
Инструменты: Экспертная оценка, администрирование претензий, анализ данных (проверки исполнения, EVM, трендов), инспекция, аудиты
Выходы: Закрытые закупки, информация об исполнении, обновления закупочной документации, запросы изменений
