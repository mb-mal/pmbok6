## Группы процессов — резюме

| Группа | Кол-во | Ключевая цель |
|--------|--------|---------------|
| **Инициация (IP)** | 2 | Авторизовать проект/фазу, определить стейкхолдеров |
| **Планирование (PL)** | 24 | Определить содержание, разработать план действий |
| **Исполнение (EX)** | 10 | Выполнить работы по плану, развивать команду |
| **Мониторинг и контроль (MC)** | 12 | Отслеживать, анализировать, корректировать |
| **Закрытие (CL)** | 1 | Формально завершить проект/фазу |

## Ключевые выходы по группам процессов

| Группа | Ключевой документ на выходе |
|--------|----------------------------|
| IP | Устав проекта |
| PL | План управления проектом + базовые планы (содержание, расписание, стоимость) |
| EX | Поставляемые результаты, данные об исполнении |
| MC | Отчёты об исполнении, одобренные запросы изменений |
| CL | Передача продукта, финальный отчёт |
