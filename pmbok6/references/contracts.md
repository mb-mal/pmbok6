# Типы контрактов — PMBOK 6

## Классификация контрактов

```
КОНТРАКТЫ
├── С фиксированной ценой (Fixed Price)
│   ├── FF (Firm Fixed Price) — твёрдая фиксированная цена
│   ├── FPIF (Fixed Price Incentive Fee) — с поощрительным вознаграждением
│   └── FP-EPA (Fixed Price with Economic Price Adjustment) — с корректировкой цены
│
├── С возмещением затрат (Cost Reimbursable)
│   ├── CPFF (Cost Plus Fixed Fee) — издержки + фиксированное вознаграждение
│   ├── CPIF (Cost Plus Incentive Fee) — издержки + поощрительное вознаграждение
│   ├── CPAF (Cost Plus Award Fee) — издержки + премиальное вознаграждение
│   └── CPPC (Cost Plus Percentage of Cost) — ⚠️ ЗАПРЕЩЁН в госзакупках США
│
└── Время и материалы (Time & Materials — T&M)
    └── Гибридный тип: оплата за время + материалы
```

## Когда что выбирать

| Тип | Риск покупателя | Риск продавца | Когда применять |
|-----|-----------------|---------------|-----------------|
| **FF** (Firm Fixed Price) | Низкий | Высокий | Точное ТЗ, стабильные требования |
| **FPIF** | Средне-низкий | Высокий | ТЗ определено, нужна мотивация к экономии |
| **FP-EPA** | Средний | Средний | Долгосрочные контракты, инфляция |
| **CPFF** | Высокий | Низкий | Неопределённое содержание, нужна гибкость |
| **CPIF** | Высокий | Средне-низкий | Как CPFF, но с мотивацией к экономии |
| **CPAF** | Высокий | Низкий | Субъективная оценка исполнения |
| **T&M** | Средний | Средний | Небольшие объёмы, невозможно точно оценить |

## Расчёт поощрений

### FPIF — Point of Total Assumption (PTA)

```
PTA = [(Ceiling Price − Target Price) / Buyer's Share Ratio] + Target Cost
```

**Пример**: Target Cost = $100K, Target Price = $120K, Ceiling = $140K, Buyer Share = 70%.

PTA = ($140K − $120K) / 0.70 + $100K = $128,571.

- Факт. затраты ≤ PTA → продавец получает долю экономии
- Факт. затраты > PTA → все перерасходы на продавце

### CPIF — расчёт прибыли

```
Прибыль = Target Fee + (Target Cost − Actual Cost) × Seller's Share
```

**Пример**: Target Cost = $100K, Target Fee = $15K, Seller Share = 30%, Actual Cost = $90K.

Прибыль = $15K + ($100K − $90K) × 0.30 = **$18K**. Общая цена = $90K + $18K = $108K.

## Сравнительная таблица

| Параметр | FF | FPIF | CPFF | CPIF | T&M |
|----------|----|----- |------|------|-----|
| Объём работ определён | Да | Да | Нет | Нет | Частично |
| Мотивация к экономии | Высокая | Высокая | Низкая | Средняя | Средняя |
| Гибкость | Низкая | Средняя | Высокая | Высокая | Высокая |
| Аудит затрат | Нет | Частично | Да | Да | Да |
| Изменения (change orders) | Много | Средне | Мало | Мало | Средне |
