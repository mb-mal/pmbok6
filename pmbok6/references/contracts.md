# Типы контрактов — PMBOK 6

> Процессы закупок: `itto-procurement.md`. Расчёты: `formulas.md` §5, `worked-examples.md` §7–8, `scripts/pmcalc.js fpif|cpif`.

## Классификация

```
КОНТРАКТЫ
├── С фиксированной ценой (Fixed Price)
│   ├── FFP   — твёрдая фиксированная цена (Firm Fixed Price)
│   ├── FPIF  — фиксированная цена с поощрительным вознаграждением
│   └── FP-EPA — фиксированная цена с экономической корректировкой (инфляция, индексы)
├── С возмещением затрат (Cost-Reimbursable)
│   ├── CPFF  — затраты + фиксированное вознаграждение
│   ├── CPIF  — затраты + поощрительное вознаграждение (доли экономии/перерасхода)
│   └── CPAF  — затраты + премиальное вознаграждение (субъективная оценка покупателя)
└── Время и материалы (T&M) — гибрид: ставка × время + материалы
```

CPPC (затраты + процент от затрат) в PMBOK 6 не описан; упоминается в старых изданиях как **худший для покупателя** — продавцу выгодно увеличивать затраты. В госзакупках США запрещён.

## Когда что выбирать

| Тип | Риск покупателя | Риск продавца | Когда применять |
|---|---|---|---|
| **FFP** | Низкий | Высокий | Содержание чётко определено и стабильно |
| **FPIF** | Низкий–средний | Высокий | Содержание определено, нужна мотивация по стоимости/срокам/качеству |
| **FP-EPA** | Средний | Средний | Многолетние контракты, валютные/инфляционные риски |
| **T&M** | Средний | Средний | Быстрый старт, небольшие объёмы, неясное содержание, доп. персонал |
| **CPIF** | Высокий | Средний | Содержание неясно, но есть целевые затраты для мотивации |
| **CPFF** | Высокий | Низкий | Содержание неясно, НИОКР, высокая неопределённость |
| **CPAF** | Высокий | Низкий | Исполнение трудно измерить объективно |

**Правило:** чем **лучше определено содержание**, тем правее выбор к фиксированной цене. Чем выше неопределённость, тем больше риска несёт покупатель.

## Сравнение

| Параметр | FFP | FPIF | T&M | CPIF | CPFF |
|---|---|---|---|---|---|
| Содержание определено | Полностью | Полностью | Частично | Нет | Нет |
| Мотивация продавца снижать затраты | Высокая | Высокая | Низкая | Средняя | Низкая |
| Гибкость для покупателя | Низкая | Низкая | Высокая | Высокая | Высокая |
| Аудит затрат продавца | Нет | Частично | Да (часы) | Да | Да |
| Стоимость изменений для покупателя | Высокая — каждое изменение переоформляется | Высокая | Низкая | Низкая | Низкая |
| Нагрузка на администрирование | Низкая | Средняя | Средняя (нужен лимит) | Высокая | Высокая |

⚠️ T&M без **лимита (not-to-exceed)** легко превращается в открытый бюджет. Для FFP главная опасность — плохое SOW: споры и претензии.

## Расчёт поощрений

### FPIF — точка полного принятия (PTA)
```
PTA = (Потолок цены − Целевая цена) / Доля покупателя + Целевые затраты
Прибыль = Целевая прибыль + (Целевые затраты − Факт) × Доля продавца
Цена    = min(Факт + Прибыль, Потолок цены)
```
**Пример** (целевые затраты 100 000, прибыль 10 000, потолок 120 000, 70/30):
PTA = 10 000 / 0,7 + 100 000 = **114 286**. Выше PTA — весь перерасход на продавце.

### CPIF
```
Вознаграждение = Целевое вознаграждение + (Целевые затраты − Факт) × Доля продавца
(с учётом минимального и максимального вознаграждения)
Цена = Факт + Вознаграждение
```
**Пример** (100 000 / 15 000 / 70-30 / факт 90 000): вознаграждение **18 000**, цена **108 000**.

## Документы и термины

| Термин | Суть |
|---|---|
| **SOW** (ТЗ на закупку) | Описание работ, достаточное для оценки продавцом |
| **RFI / RFQ / RFP** | Запрос информации / котировок (цена) / предложений (решение) |
| **Независимая оценка стоимости** | Собственная оценка покупателя для проверки предложений |
| **Критерии выбора** | Понимание потребности, стоимость жизненного цикла, технические возможности, риски, опыт, финансовая устойчивость, права ИС |
| **Претензия (claim)** | Спорное изменение; решается переговорами → ADR → суд |
| **Privity** | Договорные отношения — только между сторонами контракта |
| **Force majeure** | Обстоятельства непреодолимой силы |
| **Письмо о намерениях (LoI)** | Не контракт; намерение заключить |
| **Контракт — зона ответственности** | Изменения только через уполномоченного по контрактам (contract administrator) |
