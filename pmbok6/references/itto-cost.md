# 7. Управление стоимостью проекта — ITTO

> ФСП — EEF · АПО — OPA · ИСУП — PMIS. Термины: `glossary.md`. Расчёты: `formulas.md`, `worked-examples.md`, `scripts/pmcalc.js`.

**Структура бюджета (снизу вверх):**
```
Оценки операций → + резерв на непредвиденные операций → оценки пакетов работ
→ + резервы на непредвиденные (известные риски) → контрольные счета
= БАЗОВЫЙ ПЛАН ПО СТОИМОСТИ (BAC, PMB)
→ + управленческий резерв (неизвестные риски) = БЮДЖЕТ ПРОЕКТА
```
Резерв на непредвиденные использует РП; управленческий резерв — требует одобрения руководства, его использование **изменяет базовый план** через 4.6.

## 7.1 Планирование управления стоимостью · Plan Cost Management · Планирование
- **Входы:** устав · план УП (планы управления расписанием и рисками) · ФСП · АПО
- **Инструменты:** экспертная оценка · анализ данных · совещания
- **Выходы:** **план управления стоимостью** (единицы, точность, пороги контроля, правила измерения EV, связь с контрольными счетами, форматы отчётов)

## 7.2 Оценка стоимости · Estimate Costs · Планирование
**Суть:** приближённая оценка денежных ресурсов на выполнение работ.

- **Входы:** план УП (планы управления стоимостью и качеством, базовый план по содержанию) · документы (реестр уроков, расписание, требования к ресурсам, реестр рисков) · ФСП · АПО
- **Инструменты:** экспертная оценка · оценка **по аналогам** · **параметрическая** · **«снизу вверх»** · **трёхточечная** · анализ данных (альтернатив, **резервов**, **стоимости качества**) · ИСУП · принятие решений (голосование)
- **Выходы:** **оценки стоимости** · **основа оценок** · обновления документов

⚠️ Точность: **ROM** (грубая оценка) −25%…+75% на старте → **окончательная** −5%…+10%. «Снизу вверх» — самая точная и самая дорогая; по аналогам — быстрая и неточная.

## 7.3 Определение бюджета · Determine Budget · Планирование
**Суть:** агрегировать оценки и установить утверждённый базовый план по стоимости.

- **Входы:** план УП (планы управления стоимостью и ресурсами, базовый план по содержанию) · документы (основа оценок, оценки стоимости, расписание, реестр рисков) · бизнес-документы (бизнес-кейс, план управления выгодами) · соглашения · ФСП · АПО
- **Инструменты:** экспертная оценка · **агрегирование стоимости** · анализ данных (анализ резервов) · **анализ исторической информации** · **согласование с лимитами финансирования** · финансирование
- **Выходы:** **базовый план по стоимости** (S-кривая) · **требования к финансированию проекта** · обновления документов

## 7.4 Контроль стоимости · Control Costs · Мониторинг и контроль
**Суть:** отслеживать статус проекта и управлять изменениями базового плана по стоимости.

- **Входы:** план УП (план управления стоимостью, базовый план по стоимости, базовый план исполнения) · документы (реестр уроков) · требования к финансированию · данные об исполнении · АПО
- **Инструменты:** экспертная оценка · анализ данных (**освоенный объём**, отклонения, тренды, резервы) · **индекс производительности до завершения (TCPI)** · ИСУП
- **Выходы:** информация об исполнении · **прогнозы стоимости** (EAC) · запросы на изменение · обновления плана УП · обновления документов

⚠️ Выбор формулы EAC зависит от причины отклонения — см. `formulas.md`. TCPI > 1 → нужна эффективность выше текущей; если TCPI(BAC) нереалистичен, пересчитывай на EAC.
