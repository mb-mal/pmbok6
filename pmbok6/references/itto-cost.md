# Управление стоимостью — ITTO

## 7.1 Планирование управления стоимостью (PL)
Входы: Устав, план УП, ФСП, АПО
Инструменты: Экспертная оценка, анализ данных, совещания
Выходы: План управления стоимостью

## 7.2 Оценка стоимости (PL)
Входы: План УП, документы, ФСП, АПО
Инструменты: Экспертная оценка, оценка по аналогам, параметрическая, «снизу-вверх», трёхточечная, анализ резервов, стоимость качества, ИСУП, принятие решений
Выходы: Оценки стоимости, основа оценок, обновления документов

## 7.3 Определение бюджета (PL)
Входы: План УП, документы, бизнес-кейс, соглашения, ФСП, АПО
Инструменты: Экспертная оценка, агрегирование стоимости, анализ резервов, исторические данные, согласование лимитов финансирования, финансирование
Выходы: Базовый план по стоимости, требования к финансированию, обновления документов

## 7.4 Контроль стоимости (MC)
Входы: План УП, документы, требования к финансированию, данные исполнения, АПО
Инструменты: Экспертная оценка, анализ данных (EVM, трендов, отклонений, резервов), индекс производительности до завершения (TCPI), ИСУП
Выходы: Информация об исполнении, прогнозы стоимости, запросы изменений, обновления
