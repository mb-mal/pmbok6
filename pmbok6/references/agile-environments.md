# Гибкие, итеративные, адаптивные и гибридные среды (Приложение X3)

## Континуум жизненных циклов

Предиктивный → Итеративный → Инкрементный → Гибкий (Agile) → Гибридный

| Тип | Характеристика | Когда |
|-----|---------------|-------|
| Предиктивный | Полный план в начале, фазы последовательны | Стабильные требования |
| Итеративный | Повтор фаз, обратная связь | Сложность, уточнение |
| Инкрементный | Частая поставка готовых частей | Ускорение time-to-market |
| Гибкий | Короткие циклы + адаптация | Высокая неопределённость |
| Гибридный | Разные подходы для разных частей | Смешанные требования |

## Фазы в адаптивных проектах

- Последовательные с перекрытием: планирование фазы N+1 параллельно с исполнением фазы N
- Непрерывное наложение: все группы процессов протекают непрерывно

## Группы процессов в адаптивных средах

### Инициация
Сжатая форма. Устав — видение, границы, ключевые риски. Бюджет на поздних этапах.

### Планирование
Непрерывное перепланирование. Бэклог продукта → Product Owner. Release plan + Sprint plan.

### Исполнение
Итерации (sprints). Демонстрация после каждой. Стендапы 15 мин. Ретроспективы.

### Мониторинг и контроль
Бэклог, burn-down/burn-up charts, velocity, CFD.

### Закрытие
Формальное закрытие + ретроспектива проекта.

## Роль РП в Agile
Сервант-лидер: устраняет препятствия, фасилитирует, защищает команду.

## Артефакты
- Бэклог продукта — приоритизированные user stories
- Бэклог спринта — задачи на итерацию
- Инкремент — готовый результат
- Definition of Done — критерии готовности
- Burn-down chart — оставшаяся работа
- Velocity — story points / итерацию
