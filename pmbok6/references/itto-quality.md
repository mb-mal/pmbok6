# Управление качеством — ITTO

## 8.1 Планирование управления качеством (PL)
Входы: Устав, план УП, документы, ФСП, АПО
Инструменты: Экспертная оценка, сбор данных (бенчмаркинг, мозговой штурм, интервью), анализ данных (стоимость качества CoQ, анализ «что если»), принятие решений, отображение данных (блок-схемы, логическая модель данных, матричная диаграмма), планирование тестирования
Выходы: План управления качеством, метрики качества, обновления документов

## 8.2 Управление качеством (EX)
Входы: План УП, документы, АПО
Инструменты: Сбор данных (контрольные листы), анализ данных (анализ альтернатив, документов, процессов, первопричин), принятие решений, отображение данных (диаграмма сродства, причинно-следственная, блок-схемы, гистограммы, матричные диаграммы, диаграммы разброса), аудиты качества, дизайн для X, решение проблем, методы улучшения качества (PDCA, Six Sigma)
Выходы: Отчёты о качестве, документация тестирования, запросы изменений, обновления

## 8.3 Контроль качества (MC)
Входы: План УП, документы, одобренные запросы изменений, поставляемые результаты, данные исполнения, ФСП, АПО
Инструменты: Сбор данных (контрольные листы, выборочный контроль, анкетирование), анализ данных (проверки исполнения, анализ первопричин), инспекция, тестирование/оценка продукта, отображение данных (причинно-следственные, контрольные карты, гистограммы, диаграммы разброса), совещания
Выходы: Результаты измерений контроля качества, верифицированные поставляемые результаты, информация об исполнении, запросы изменений
