# Глоссарий RU ↔ EN и сокращения

> Русские переводы PMBOK различаются между изданиями и компаниями. При работе с пользователем используй его терминологию; при сомнениях указывай английский термин в скобках.

## Сокращения, используемые в навыке
| RU | EN | Значение |
|---|---|---|
| **ФСП** | EEF | Факторы среды предприятия |
| **АПО** | OPA | Активы процессов организации |
| **ИСУП** | PMIS | Информационная система управления проектами |
| **План УП** | PM Plan | План управления проектом |
| **РП** | PM | Руководитель проекта |
| **ИСР** | WBS | Иерархическая структура работ |
| **КП** | CP | Критический путь |
| **OBS / RBS** | OBS / RBS | Оргструктура / иерархическая структура ресурсов (RBS также — рисков) |
| **RTM** | RTM | Матрица отслеживания требований |
| **CCB** | CCB | Совет по контролю изменений |
| **PMB** | PMB | Базовый план исполнения |
| **WPD / WPI / WPR** | Work Performance Data / Information / Reports | Данные / информация / отчёты об исполнении работ |
| **IP, PL, EX, MC, CL** | IG, PG, EG, MCG, CG | Группы процессов: инициация, планирование, исполнение, мониторинг и контроль, закрытие |
