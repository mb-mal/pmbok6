# Управление расписанием — ITTO

## 6.1 Планирование управления расписанием (PL)
Входы: Устав, план УП, ФСП, АПО
Инструменты: Экспертная оценка, анализ данных, совещания
Выходы: План управления расписанием

## 6.2 Определение операций (PL)
Входы: План УП, ФСП, АПО
Инструменты: Экспертная оценка, декомпозиция, планирование методом набегающей волны, совещания
Выходы: Список операций, параметры операций, список контрольных событий, запросы изменений

## 6.3 Определение последовательности операций (PL)
Входы: План УП, документы, ФСП, АПО
Инструменты: Метод диаграмм предшествования (PDM), определение зависимостей, опережения и задержки, ИСУП
Выходы: Диаграмма сети расписания, обновления документов

## 6.4 Оценка длительности операций (PL)
Входы: План УП, документы, ФСП, АПО
Инструменты: Экспертная оценка, оценка по аналогам, параметрическая, трёхточечная (PERT), «снизу-вверх», анализ резервов, принятие решений
Выходы: Оценки длительности, основа оценок, обновления документов

## 6.5 Разработка расписания (PL)
Входы: План УП, документы, соглашения, ФСП, АПО
Инструменты: Анализ сети расписания, метод критического пути, оптимизация ресурсов (выравнивание, сглаживание), анализ «что если», сжатие расписания (fast tracking, crashing), ИСУП, agile-планирование релиза
Выходы: Базовое расписание, расписание проекта, календари, запросы изменений

## 6.6 Контроль расписания (MC)
Входы: План УП, документы, данные исполнения, АПО
Инструменты: Анализ данных (EVM, трендов, отклонений, «что если»), метод критического пути, ИСУП, сжатие расписания
Выходы: Информация об исполнении, прогнозы расписания, запросы изменений
