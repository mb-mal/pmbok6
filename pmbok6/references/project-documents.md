## 3. Бизнес-документы
- **Бизнес-кейс** — обоснование инвестиции: потребность, анализ ситуации, варианты, рекомендация. Владелец — спонсор.
- **План управления выгодами** — целевые выгоды, сроки, метрики, владелец, допущения, риски.
Оценка потребностей → бизнес-кейс → устав. Выгоды часто реализуются **после** завершения проекта.

## 4. ФСП и АПО

| | ФСП — факторы среды предприятия (EEF) | АПО — активы процессов организации (OPA) |
|---|---|---|
| Суть | Условия **вне контроля** команды, влияющие на проект | Планы, процессы, политики, базы знаний **организации** |
| Внутренние | Культура, структура, география, инфраструктура, ИТ-ПО, доступность ресурсов, компетенции персонала | **Процессы, политики, процедуры** (шаблоны, стандарты, процедуры изменений, финконтроля) |
| Внешние | Рыночные условия, законодательство, стандарты отрасли, коммерческие базы данных, академические исследования, физическая среда | **Базы знаний** (исторические данные, уроки прошлых проектов, реестры проблем и дефектов, файлы конфигураций, финансовые данные) |
| Кто меняет | Не проект | Процессы — обычно не проект (PMO); базы знаний — проект **обновляет** |
