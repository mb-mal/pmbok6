# PMBOK® Guide — Sixth Edition · Навигатор процессов

> Полная методология PMI. 5 групп процессов, 10 областей знаний, 49 процессов, Agile-адаптация.

## 🧭 Как использовать этот навык

В зависимости от задачи — открывай нужный файл:

| Нужно | Открыть |
|-------|---------|
| Понять, какой процесс запустить и когда | `references/process-map.md` — полная карта 49 процессов |
| Детально разобрать процесс (входы/инструменты/выходы) | `references/itto-{область}.md` — ITTO для конкретной области |
| Посчитать бюджет, сроки, риски | `references/formulas.md` — все формулы PMBOK |
| Выбрать тип контракта | `references/contracts.md` — типы контрактов и когда применять |
| Разобраться в Agile-подходе по PMBOK | `references/agile-environments.md` — адаптивные среды |
| Адаптировать процессы под проект | `references/tailoring.md` — соображения по адаптации |
| Подготовиться к PMP экзамену | `references/key-concepts.md` — ключевые концепции областей знаний |
| Создать устав, ИСР, реестр рисков | `templates/` — шаблоны документов |

## 📖 Об этом навыке

Навык создан на основе полного русского перевода **PMBOK® Guide — Sixth Edition** (Project Management Institute, 2017, ISBN 978-1-62825-193-7) — 762 страницы оригинального PDF.

**Как создавался:**
- PDF-файл `PMBOK-6th-Edition-Ru.pdf` (762 стр.) полностью разобран через PyPDF2
- Извлечены: оглавление, 13 глав руководства, стандарт управления проектом, 5 приложений (X1–X5)
- Каждый раздел PMBOK распределён по отдельному `.md`-файлу в соответствии с логической структурой:
  - **references/** — справочные материалы (17 файлов: карта процессов, формулы, ITTO по 10 областям знаний, контракты, agile, адаптация, ключевые концепции)
  - **templates/** — готовые к заполнению шаблоны (4 файла: устав, ИСР, реестр рисков, реестр стейкхолдеров)
  - **SKILL.md** — оркестратор: навигация, алгоритмы выбора процессов, быстрые ссылки

**Охват:** 5 групп процессов, 10 областей знаний, 49 процессов с полными ITTO, все формулы EVM/PERT/контрактов, Agile-адаптация по PMBOK, изменения между 5-м и 6-м изданиями.
